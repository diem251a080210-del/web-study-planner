# Web Study Planner

Ứng dụng danh sách việc học bằng HTML, CSS và JavaScript thuần. Có thể thêm việc, đánh dấu hoàn thành, xóa việc; dữ liệu lưu bằng `localStorage` trên thiết bị đang dùng.

## Chạy

Mở `index.html` trong trình duyệt. Không cần cài thư viện hay tài khoản.

Gợi ý tự phát triển: thêm ngày hạn, lọc việc đã xong, hoặc xuất dữ liệu JSON.
